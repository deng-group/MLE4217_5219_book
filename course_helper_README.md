# Course Helper

The course helper is a small question window inside the MLE4217/5219 course book. It is designed to help you review course material, find relevant sections, and connect ideas across topics.

## What You Can Ask

Good questions include:

- What is a convex hull, and why is it useful?
- How do I construct a BaTiO3 structure?
- What is the difference between molecular dynamics and Monte Carlo?
- How is Materials Project data used in machine learning workflows?
- Where can I find the example for local optimization?
- What should I review before studying MACE potentials?

You can ask conceptual questions, code or workflow questions, and questions that connect multiple course topics.

## What To Expect

The helper answers using the course materials first. When it can find relevant material, it will usually start by pointing you to the course section or file where the answer comes from.

For code-related questions, it may provide example code based on the course notebooks. For broader questions, it may give a short explanation and suggest how the topic relates to nearby concepts.

## Important Notes

- The helper is not a general chatbot. It is meant for this course.
- If the course materials do not contain enough evidence, it may say that it cannot answer confidently.
- For syllabus, grading, deadlines, quizzes, exams, and schedule questions, always check the academic year and semester. The current course logistics in the helper are for **AY2025/2026 Semester 2**.
- The chat only keeps short memory while the current page/tab is open. If you close or reload the page, the helper may not remember earlier questions.
- Answers are study support, not official policy. For high-stakes course logistics, confirm with the syllabus, calendar, or teaching team.

## Tips

Specific questions work best. Instead of asking "explain everything about structures," try "how do fractional coordinates relate to the unit cell?" or "how do I build a perovskite structure in ASE?"

If an answer seems too broad or misses your intent, ask a follow-up with more context.
